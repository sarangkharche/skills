# Ginormous Figma

Read and apply the smallest set of guides that covers the request. Follow the requested scope and preserve the existing design system. For a review, report findings. Apply edits when requested.

* For overall interface quality, read [figma-better-interface](references/figma-better-interface.md).
* For screen critique, read [superfuture-design-review](references/superfuture-design-review.md).
* For component audits, read [analyze-components](references/analyze-components.md).
* For developer handoff, read [component-handoff](references/component-handoff.md).
* For component anatomy annotations, read [create-anatomy](references/create-anatomy.md).
* For adapting desktop frames for mobile, read [desktop-to-mobile](references/desktop-to-mobile.md).
* For padding, gaps and margins, read [spacing-audit](references/spacing-audit.md).
* For interface copy, read [balise-ux-writing](references/balise-ux-writing.md).
* For identifying useful motion, read [find-animation-opportunities](references/find-animation-opportunities.md).
